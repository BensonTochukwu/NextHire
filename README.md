# 🚀 NextHire - Job Portal Platform

NextHire is a full-stack job portal web application built with the MERN stack that connects recruiters with job seekers. Recruiters can post and manage job listings, while users can browse jobs, apply, and upload resumes through a secure and modern interface.

The platform features authentication, role-based access control, webhook-based user sync, and cloud file handling for resumes and profile images.

---

## ✨ Features

### 👤 Authentication & Users
- Secure authentication using Clerk
- Role-based access (Recruiter / Job Seeker)
- Webhook-based user synchronization with MongoDB

### 💼 Job System
- Recruiters can post, edit, and manage jobs
- Users can browse and filter job listings
- Apply to jobs with a single click

### 📄 Resume System
- Resume upload functionality
- Cloudinary integration for file storage
- Resume access for recruiters

### 🧑‍💼 Recruiter Dashboard
- Add new job listings
- Manage posted jobs
- View job applications

### ⚙️ System Features
- Protected routes and middleware authentication
- RESTful API architecture
- Responsive UI with Tailwind CSS
- Backend hosted on Render
- Frontend hosted on Vercel
